# WAQT 5.6.0 – Focus, Recorder & Settings Polish

- Refined the Pomodoro dial for Light Mode: removed the irregular black drop shadow, switched to a soft blue glass bezel/disc, and reduced progress glow.
- Rebuilt the journal voice recorder as one focused glass dialog with elapsed-time display and Start / Stop & Save / Cancel controls.
- Made first-run permission guidance explicitly optional; permissions are requested only when the related feature is used or the user opens the permissions section.
- Disabled automatic update checks by default. Users can opt in from Settings; manual update checks remain available.
- Update prompts now offer explicit “Yes, download update” and “No, later” actions. WAQT does not silently install APK updates.
- Version bumped to 5.6.0 (versionCode 26).

Build status: ZIP integrity can be checked locally; Android Gradle build was not run in this environment.
